This project ships two compiled audio engines inside `wasm/`. They are built
from unmodified upstream sources by `tools/build-wasm.sh`, which clones them
into `vendor-src/` (git-ignored) on first run.

LGPL compliance for a web deployment:

1. **Source availability** — the exact sources are public upstream, and
   `tools/build-wasm.sh` in this repository reproduces the shipped binaries
   byte-for-byte from them (it documents the compiler flags, the SDK version and
   the bridge code, which is also part of this source tree).
2. **Relinking** — the engine is a separate WASM module loaded by the page, so a
   user who wants a modified libgme can rebuild `wasm/gme.wasm` with the script
   and drop the file in; no changes to the rest of the application are needed.
3. **Notices** — this file is part of the distributed source tree.
